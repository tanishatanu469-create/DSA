# 📦 Inventory Management System (Java)

A Java-based **Inventory Management System** developed using Java Swing and ArrayList to simplify product management and stock monitoring. The application provides a graphical user interface to add, view, search, update, delete, and sort product records.

## 🚀 Project Overview

The Inventory Management System is designed to manage product information efficiently. It allows users to maintain product details such as Product ID, Product Name, Quantity, and Price through an interactive desktop application.

This project demonstrates the practical implementation of Java programming, Object-Oriented Programming (OOP), Data Structures, and GUI development.

## ✨ Features

- **Add Product:** Add new products with ID, name, quantity, and price.
- **View Inventory:** Display all available products in a table.
- **Search Product:** Search products by ID or name.
- **Update Product:** Modify existing product information.
- **Delete Product:** Remove products from inventory.
- **Sort Products:** Arrange products according to price.
- **Low Stock Alert:** Identify products with low available quantities.
- **User-Friendly GUI:** Easy-to-use interface developed using Java Swing.

## ⚙️ Installation and Setup

### Prerequisites

- Java Development Kit (JDK 17 or above)
- VS Code / IntelliJ IDEA / Eclipse
- Basic knowledge of Java

### Steps to Run

**1. Clone the repository**

```bash
git clone https://github.com/your-username/Inventory-Management-System.git
```

**2. Navigate to the project directory**

```bash
cd Inventory-Management-System
```

**3. Compile the Java file**

```bash
javac InventoryPrototype.java
```

**4. Run the application**

```bash
java InventoryPrototype
```

The Inventory Management System window will open.
